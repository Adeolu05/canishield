# Fonts for the NU7 share cards

TTF copies of Inter Tight (Bold, Medium), Instrument Serif (Italic) and
JetBrains Mono (Medium), Latin subsets. All three families are licensed under
the SIL Open Font License 1.1 (https://openfontlicense.org). `next/og` needs
TTF, OTF or WOFF, so these are converted from the WOFF2 files and read from
disk by `src/lib/nu7-card.tsx`.
