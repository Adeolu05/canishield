# Fonts for the share cards

TTF copies, Latin subsets, all licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). `next/og` needs TTF, OTF or WOFF, so these are
read from disk at request time.

- Inter Tight (Bold, Medium), Instrument Serif (Italic) and JetBrains Mono
  (Medium): the NU7 share cards, `src/lib/nu7-card.tsx`.
- Geist (Regular, Medium, SemiBold) and Geist Mono (Medium), the site's own
  typefaces: the board and service link previews, `src/lib/og.tsx`.
